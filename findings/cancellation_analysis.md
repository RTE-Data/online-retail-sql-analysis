### Cancellation Analysis

The dataset contains **3,836 cancelled invoices**, representing approximately **14.8% of all invoices**. These cancellations account for **9,288 transaction rows** with a combined value of **−£896,812.49**.

When compared with the value of non-cancelled transactions, the absolute value of cancellations represents approximately **8.43%** of non-cancelled transaction value.

The difference between the invoice rate and value percentage suggests that cancelled transactions represent a notable proportion of invoice activity, while their financial impact is somewhat lower relative to completed transaction value. This analysis treats invoices beginning with **"C"** as cancellations based on the dataset's invoice-number convention.
